  ┌─ STEP 1 ──────────────────────────────────────────────────────────────┐
  │  📥  Clone โปรเจกต์                                                   │
  └───────────────────────────────────────────────────────────────────────┘

    git clone https://github.com/TengFk7/resolvenow.git
    cd resolvenow


  ┌─ STEP 2 ──────────────────────────────────────────────────────────────┐
  │  📦  ติดตั้ง Dependencies                                             │
  └───────────────────────────────────────────────────────────────────────┘

    npm install

    รอสักครู่... ระบบจะติดตั้ง packages ทั้งหมด ได้แก่:
    • express, mongoose, socket.io
    • bcryptjs, express-session, connect-mongo
    • nodemailer, cloudinary, multer
    • helmet, express-rate-limit, xss
    • @anthropic-ai/sdk, exceljs, และอื่นๆ


  ┌─ STEP 3 ──────────────────────────────────────────────────────────────┐
  │  ⚙️   สร้างไฟล์ .env                                                  │
  └───────────────────────────────────────────────────────────────────────┘

    คัดลอกไฟล์ตัวอย่าง:

    Windows:   copy .env.example .env
    Mac/Linux: cp .env.example .env

    จากนั้นเปิดไฟล์ .env และแก้ไขค่าตามที่อธิบายใน [4]


  ┌─ STEP 4 ──────────────────────────────────────────────────────────────┐
  │  🌿  ตั้งค่า MongoDB Atlas                                             │
  └───────────────────────────────────────────────────────────────────────┘

    1. สร้าง Cluster ฟรี (M0) ที่ https://www.mongodb.com/cloud/atlas
    2. สร้าง Database User (username + password)
    3. เพิ่ม IP Address: 0.0.0.0/0 (Allow All) ใน Network Access
    4. คัดลอก Connection String มาใส่ใน MONGODB_URI
       ตัวอย่าง:
       MONGODB_URI=mongodb+srv://myuser:mypass@cluster0.xxxxx.mongodb.net/resolvenow


  ┌─ STEP 5 ──────────────────────────────────────────────────────────────┐
  │  📧  ตั้งค่า Gmail สำหรับส่ง OTP                                      │
  └───────────────────────────────────────────────────────────────────────┘

    1. ไปที่ https://myaccount.google.com/security
    2. เปิด "2-Step Verification"
    3. ไปที่ https://myaccount.google.com/apppasswords
    4. สร้าง App Password → เลือก "Mail" และ "Other"
    5. คัดลอก 16 ตัวอักษรมาใส่ MAIL_PASS


  ┌─ STEP 6 ──────────────────────────────────────────────────────────────┐
  │  ☁️   ตั้งค่า Cloudinary สำหรับอัปโหลดรูป                            │
  └───────────────────────────────────────────────────────────────────────┘

    1. สมัครที่ https://cloudinary.com/ (ฟรี)
    2. ไปที่ Dashboard → คัดลอก:
       • Cloud Name  → CLOUDINARY_CLOUD_NAME
       • API Key     → CLOUDINARY_API_KEY
       • API Secret  → CLOUDINARY_API_SECRET


  ┌─ STEP 7 ──────────────────────────────────────────────────────────────┐
  │  💬  ตั้งค่า LINE (ไม่บังคับ แต่แนะนำ)                               │
  └───────────────────────────────────────────────────────────────────────┘

    A) LINE Messaging API (สำหรับ Push Notification):
       1. https://developers.line.biz/ → สร้าง Messaging API Channel
       2. Channel Management → Messaging API tab
       3. คัดลอก Channel Access Token → LINE_CHANNEL_TOKEN
       4. หา LINE User ID ของตัวเอง → LINE_ADMIN_USER_ID

    B) LINE Login (สำหรับ Login ผ่าน LINE):
       1. สร้าง LINE Login Channel ใหม่
       2. คัดลอก Channel ID     → LINE_LOGIN_CLIENT_ID
       3. คัดลอก Channel Secret  → LINE_LOGIN_CLIENT_SECRET
       4. เพิ่ม Callback URL:
          https://your-domain.onrender.com/auth/line/callback

    C) LINE LIFF (สำหรับ Rating ดาว):
       1. ใน Messaging API Channel → LIFF tab
       2. สร้าง LIFF ใหม่:
          • Size: Compact
          • Endpoint URL: https://your-domain.onrender.com/liff-rating
          • Scopes: profile
       3. คัดลอก LIFF ID → LINE_LIFF_ID
