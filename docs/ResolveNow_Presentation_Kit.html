3. Ticket State Flow (State Flow ของการรับร้องเรียน)

การเปลี่ยนสถานะ (State Flow) ตั้งแต่จังหวะที่ประชาชนเริ่มกดแจ้ง ไปจนจบกระบวนการการประเมินดาว (Rating)

Admin จ่ายงาน (Smart Queue) pending --> in_progress : 2b. ช่างกดรับงานเอง (Auto) assigned --> in_progress : 3. ช่างลงพื้นที่และเริ่มงาน in_progress --> completed : 4. ช่างอัปโหลดภาพ Before/After pending --> rejected : 2c. ข้อมูลซ้ำซ้อน/Admin ปฏิเสธ completed --> [*] : 5. ประชาชนให้คะแนน (Rating) rejected --> [*] : 6. จบกระบวนการ (ไม่ผ่าน)
