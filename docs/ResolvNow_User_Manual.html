คู่มือการใช้งานระบบ ResolveNow
แอปพลิเคชันจัดการเรื่องร้องเรียน

เอกสารฉบับนี้อธิบายวิธีการใช้งานสำหรับ ผู้แจ้งปัญหา (Citizen), เจ้าหน้าที่ช่าง (Technician) และผู้ดูแลระบบ (Admin) โดยละเอียด

CITIZEN 1. การใช้งานสำหรับประชาชน (ผู้แจ้งปัญหา)

ในฐานะประชาชน คุณสามารถแจ้งปัญหาต่างๆ ภายในพื้นที่ ติดตามความคืบหน้า และสื่อสารกับเจ้าหน้าที่ได้อย่างรวดเร็ว

1.1 การเข้าสู่ระบบ (Login & Register)

  1. เข้าใช้งานผ่านอีเมล: กรอกอีเมลและรหัสผ่านที่คุณได้ลงทะเบียนไว้เพื่อเข้าสู่ระบบ
  2. เชื่อมต่อด้วย LINE (LINE Login): เพื่อความสะดวกสูงสุด คุณสามารถกดปุ่ม "Login with LINE" ระบบจะดึงข้อมูลโปรไฟล์และสามารถส่งข้อความแจ้งเตือนสถานะต่างๆ ผ่าน LINE ได้ทันที

1.2 การสร้างรายการแจ้งปัญหา (Create Ticket)

  1. กดปุ่ม "แจ้งปัญหาใหม่ (New Ticket)" จากหน้า Dashboard หรือหน้าจัดการส่วนตัว
  2. ระบุหมวดหมู่: เลือกประเภทของปัญหา (เช่น ถนน/ทางเท้า, แสงสว่าง, น้ำประปา ฯลฯ)
  3. อธิบายรายละเอียด: พิมพ์อาการหรือปัญหาที่พบเจอ เพื่อให้ช่างเตรียมเครื่องมือได้ถูกต้อง
  4. แนบรูปภาพ: ถ่ายภาพหรือเลือกรูปจากมือถืออัปโหลดเป็นหลักฐาน (รูปภาพก่อนการแก้ไข)
  5. ระบุตำแหน่ง: ปักหมุดบนแผนที่ หรือปล่อยให้ระบบดึงตำแหน่ง GPS ปัจจุบัน
  6. กด "ส่งข้อมูล (Submit)" เมื่อเสร็จสิ้น คุณจะได้รับหมายเลขอ้างอิง (เช่น TKT-001) ไว้สำหรับติดตามผล

1.3 การติดตามสถานะและแชทกับช่าง (Tracking & Chat)

เมื่อปัญหาถูกส่งเข้าระบบ สถานะต่างๆ จะถูกอัปเดตแบบเรียลไทม์:

  • Pending: รอแอดมินหรือระบบแจกจ่ายงาน
  • Assigned: ช่างรับเรื่องแล้วและเตรียมเดินทาง
  • In Progress: ช่างกำลังดำเนินการซ่อมแซม
  • Completed: งานซ่อมแซมเสร็จสิ้นสมบูรณ์

นอกจากนี้ คุณสามารถเข้าไปที่รายละเอียดของปัญหา เพื่อเข้าไปพิมพ์ "พูดคุย (Comment)" กับเจ้าหน้าที่ช่าง หรือแอดมิน เพื่อส่งตำแหน่งเพิ่มเติมหรือความคืบหน้าต่างๆ ได้ตลอดเวลา

1.4 การโหวตและติดตามปัญหาของผู้อื่น (Upvotes & Followers)

หากคุณพบว่าจุดที่มีปัญหา มีการรับชมบนหน้ากระดานสาธารณะ (Public Feed) คุณสามารถ:

  • กดติดตาม (Follow): เพื่อรับการแจ้งเตือนความคืบหน้าของปัญหานั้นประหนึ่งว่าคุณเป็นคนแจ้งเอง
  • กดโหวต (Upvote): เพื่อผลักดันและบอกระบบว่าปัญหานี้มีความสำคัญและกระทบต่อคนหมู่มาก (ระบบ Smart Queue จะจัดให้เป็นเคสคิวแรกๆ)

1.5 การประเมินผลงาน (Review & Rating)

เมื่อเจ้าหน้าที่ซ่อมแซมเสร็จสิ้น (สถานะเป็น Completed) ระบบจะเปิดให้คุณสามารถให้คะแนน (1-5 ดาว) พร้อมพิมพ์ข้อความติชม เพื่อเป็นขวัญกำลังใจและเป็นข้อมูลอ้างอิงให้ผู้ดูแลระบบตรวจสอบมาตรฐานได้

TECHNICIAN 2. การใช้งานสำหรับเจ้าหน้าที่ช่าง

ในฐานะเจ้าหน้าที่ช่าง ระบบจะช่วยจัดคิวงาน นำทาง และใช้เป็นเครื่องมือยืนยันผลการทำงานของคุณ

2.1 การรับงานและปฎิบัติงาน (Job Assignment)

  1. หน้า Dashboard ส่วนตัว: เมื่อคุณล็อกอินเข้ามา จะพบรายการปัญหาที่ผู้ดูแลระบบ Assign มาให้ หรือคุณสามารถกด "รับงาน (Accept)" จากกองกลางได้เอง
  2. อัปเดตสถานะ: เมื่อเริ่มออกปฏิบัติงาน ให้กดเปลี่ยนสถานะเป็น "In Progress" เพื่อให้ประชาชนทราบว่ากำลังดำเนินการ
  3. การค้นหาเส้นทาง: สามารถแตะที่แผนที่ของปัญหานั้นๆ เพื่อนำทางไปยังพิกัด (GPS) จากแอปพลิเคชันนำทางที่คุณมี

2.2 การส่งานและรูปภาพหลักฐาน (Before & After Images)

การยืนยันการทำงานเป็นสิ่งสำคัญ เมื่อคุณไปถึงหน้างานและซ่อมเสร็จแล้ว ระบบบังคับว่า:

  • ให้ช่างอัปโหลดภาพ ก่อนการแก้ไข (Before Image) (หากประชาชนยังไม่ได้อัปโหลด หรือต้องการภาพมุมกว้างกว่า)
  • ให้ช่างอัปโหลดภาพ หลังการแก้ไขเสร็จสิ้น (After Image) เพื่อเป็นหลักฐานว่างานได้แก้ไขลุล่วงแล้ว จากนั้นจึงสามารถเปลี่ยนสถานะเป็น Completed ได้

2.3 การขอความช่วยเหลือ (Help Requests)

หากปัญหาหน้างานซับซ้อนเกินกว่าช่างคนเดียว หรือข้ามขอบเขตหน่วยงาน คุณสามารถสร้าง "ขอความช่วยเหลือ (Help Request)"

  • ระบุรายละเอียดสิ่งที่ต้องการสนับสนุน
  • กำหนดหน่วยงานเป้าหมาย (Target Department) หรือส่งให้ส่วนกลาง
  • ช่างแผนกอื่น หรือตัวเจ้าหน้าที่รัฐส่วนอื่น จะสามารถมองเห็นและเข้ามากด “รับงานช่วยเหลือ” (Accept Request) ได้ทันที

ADMIN 3. การใช้งานสำหรับผู้ดูแลระบบ (Admin)

ผู้ดูแลระบบจะมีสิทธิ์ในการมองเห็นข้อมูลทั้งหมด ควบคุมการทำงานของเจ้าหน้าที่ และจัดการข้อมูลเชิงระบบ

3.1 ระบบจัดการคิวอัจฉริยะ (Smart Queue System)

ที่หน้า Dashboard ของ Admin จะสังเกตเห็นคิวงานที่เรียงลำดับความสำคัญให้แล้วอัตโนมัติ โดยอิงจาก:

  • คะแนนความเร่งด่วน (Priority Score): ที่ระบบคำนวนให้จาก Urgency Level และความถี่ผู้โหวต (Upvotes)
  • ระบบแจ้งเตือน SLA (SLA Monitoring): หากใกล้ถึงวันหมดอายุ (Deadline) หรือละเมิดข้อตกลงในการให้บริการ กรอบงานจะแสดงสีแดง เพื่อให้แอดมินเร่งจ่ายงาน

คุณสามารถลาก (Drag) หรือกดเลือกรายการเพื่อมอบหมายงาน (Assign) งานให้กับช่างที่ว่างและเชี่ยวชาญในด้านนั้นๆ ประจำกะงานนั้นได้

3.2 จัดการผู้ใช้งานและหมวดหมู่ (User & Category Management)

  • การเพิ่ม/ลด หมวดหมู่ปัญหา: เข้าไปที่เมนู Category Management เพื่อสร้างประเภทปัญหาใหม่ (เช่น ไฟไหม้, กิ่งไม้หักทับสายไฟ) พร้อมใส่ไอคอน (Emoji) แสดงผลได้ทันที
  • จัดการบทบาท: สามารถโปรโมทบุลคลจาก Citizen ขึ้นมาเป็น Technician หรือ Admin รวมถึงสามารถแบนบัญชีชั่วคราวได้
